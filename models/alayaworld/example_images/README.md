# AlayaWorld example images

Upload either PNG in this directory through `set_image`. Both files are
unmodified 1672×941 RGB images copied from the public AlayaWorld playground at
revision [`1abbe2e`](https://github.com/AlayaLab/AlayaWorld/tree/1abbe2e196603ef9f8eeedfddd427b4d37d57bc1/playground).
The adapter center-crops and resizes an upload to the model's 960×544 input at
runtime.

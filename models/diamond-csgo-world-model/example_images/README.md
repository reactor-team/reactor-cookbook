# Example spawn images

These images are example CSGO initial conditions extracted from the public
`csgo/spawn` bundle distributed with `eloialonso/diamond` revision
`5d4abca9af6ab1b3ab1c6fc228cacb7281130f7f`.

Each PNG is an unchanged 280×150 RGB conditioning frame. They are included so
a client can exercise `set_spawn_image` without finding a compatible source
image first. The filenames describe the visible Dust II location rather than a
stable upstream scene identifier.

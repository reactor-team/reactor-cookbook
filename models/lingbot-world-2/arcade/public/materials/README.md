# Material sources

The architectural surface maps in this directory come from ambientCG and are
released under CC0 1.0.

- `floor-concrete040`: ambientCG Concrete 040
  - https://ambientcg.com/view?id=Concrete040
- `wall-concrete024`: ambientCG Concrete 024
  - https://ambientcg.com/view?id=Concrete024

Each set includes 2048 px color, OpenGL normal, roughness, and displacement
maps. They have been renamed for concise local use; their pixel content is
otherwise unchanged.
